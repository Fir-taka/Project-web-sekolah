SAMBUTAN KEPALA JURUSAN TKJT

Kepala Jurusan TKJT

Teknik Komputer Jaringan dan Telekomunikasi

Selamat datang di program keahlian Teknik Komputer Jaringan dan Telekomunikasi (TKJT).

Program TKJT mempersiapkan lulusan untuk menjadi profesional infrastruktur jaringan, administrator sistem, dan teknisi telekomunikasi yang handal. Kami menyediakan pelatihan intensif dengan peralatan networking terkini agar siswa dapat menguasai teknologi terdepan dalam industri telekomunikasi dan IT.

Kurikulum kami dirancang sesuai standar industri internasional, dengan fokus pada praktik langsung dan sertifikasi profesional seperti Cisco dan CompTIA untuk meningkatkan daya saing lulusan di pasar kerja global.

Materi Pembelajaran TKJT

Tiga fokus utama dalam program keahlian ini

Infrastruktur Jaringan

Perancangan dan implementasi infrastruktur jaringan komputer yang handal dan efisien untuk berbagai skala organisasi.

  • Cisco Networking
  • Routing & Switching
  • Wireless Networks
  • Network Troubleshooting

Administrasi Server

Mengelola dan mengadministrasi server dengan berbagai sistem operasi untuk mendukung kebutuhan organisasi.

  • Windows Server
  • Linux Server
  • Database Server
  • Backup & Recovery

Sistem Telekomunikasi

Mempelajari sistem telekomunikasi modern termasuk VoIP dan komunikasi terpadu untuk bisnis.

  • VoIP Systems
  • Fiber Optic
  • Mobile Networks
  • IoT Systems

Kompetensi yang Dikuasai

Lulusan TKJT siap dengan skill industri

Network Design

Merancang topologi jaringan yang optimal untuk berbagai kebutuhan organisasi.

Server Management

Mengelola dan memaintenance server untuk uptime maksimal dan performa optimal.

Network Security

Implementasi keamanan jaringan untuk melindungi data dan sistem dari ancaman cyber.

Routing & Switching

Konfigurasi router dan switch Cisco untuk jaringan enterprise yang scalable.

Wireless Networks

Instalasi dan konfigurasi jaringan wireless (WiFi) untuk jangkauan luas.

Troubleshooting

Diagnosa dan pemecahan masalah jaringan dengan cepat dan efisien.
