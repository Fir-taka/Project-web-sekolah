SAMBUTAN KEPALA JURUSAN PPLG

Kepala Jurusan PPLG

Pengembangan Perangkat Lunak dan Gim

Selamat datang di program keahlian Pengembangan Perangkat Lunak dan Gim (PPLG).

Program PPLG dirancang untuk mempersiapkan peserta didik menjadi profesional programmer dan game developer yang kompeten dan siap menghadapi tantangan industri software modern. Kami mengintegrasikan kurikulum terkini dengan praktik industri nyata untuk memastikan lulusan kami mampu bersaing di pasar kerja global.

Dengan fasilitas laboratorium yang lengkap dan instruktur berpengalaman, kami memberikan pendidikan berkualitas tinggi yang menggabungkan teori dan praktik langsung dalam pengembangan aplikasi web, mobile, dan game development.

Materi Pembelajaran PPLG

Tiga fokus utama dalam program keahlian ini

Web Development

Mempelajari pembuatan website modern menggunakan HTML, CSS, JavaScript, dan framework seperti React, Vue, atau Laravel.

  • Frontend Development
  • Backend Development
  • Database Design
  • Web Security

Mobile App Development

Mengembangkan aplikasi mobile untuk iOS dan Android menggunakan berbagai teknologi dan framework populer.

  • Kotlin & Java (Android)
  • Swift (iOS)
  • Flutter & React Native
  • UI/UX Design

Game Development

Membuat game 2D dan 3D menggunakan engine game profesional seperti Unity dan Unreal Engine.

  • Unity Game Engine
  • Unreal Engine
  • Game Design
  • Graphics & Animation

Kompetensi yang Dikuasai

Lulusan PPLG siap dengan skill industri

Programming Languages

Python, Java, C++, JavaScript, Kotlin, Swift, dan bahasa pemrograman lainnya.

Database Management

MySQL, PostgreSQL, MongoDB, Firebase untuk mengelola data aplikasi.

Version Control

Git, GitHub untuk kolaborasi dan manajemen source code profesional.

UI/UX Design

Figma, Adobe XD untuk membuat antarmuka aplikasi yang menarik dan user-friendly.

Game Development

Unity, Unreal Engine untuk membuat game berkualitas profesional.

Security & Testing

Testing, debugging, dan implementasi keamanan dalam aplikasi.
